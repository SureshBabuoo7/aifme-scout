# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in AIFME Scout OSS, please report it responsibly.

**Do not** open a public issue for security vulnerabilities.

Instead, please email security@aifme.com with:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 5 business days and work with you to coordinate a fix and disclosure timeline.
