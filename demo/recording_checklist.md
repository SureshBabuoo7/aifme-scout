# Recording Checklist

Use this checklist to create the AIFME Scout OSS v1.0.0 demo video.

## Pre-Production

- [ ] Clean terminal profile (high contrast, large font)
- [ ] Close unnecessary applications
- [ ] Disable notifications
- [ ] Set up microphone (if narrating)
- [ ] Install AIFME Scout OSS in a fresh virtual environment
- [ ] Verify all commands work as expected
- [ ] Prepare talking points from `demo_script.md`

## Recording

- [ ] Record at 1080p minimum, 60fps preferred
- [ ] Record full demo in one take (3 minutes)
- [ ] Record voiceover (optional)
- [ ] Capture all required screenshots (see `screenshots.md`)

## Post-Production

- [ ] Edit video to 3 minutes or less
- [ ] Add chapter markers:
  - [ ] 0:00 — Setup
  - [ ] 0:00–0:45 — Basic Scan
  - [ ] 0:45–1:30 — Markdown Report
  - [ ] 1:30–2:15 — JSON Output
  - [ ] 2:15–2:45 — REST API
  - [ ] 2:45–3:00 — Closing
- [ ] Add title: "AIFME Scout OSS v1.0.0 — Demo"
- [ ] Add description with links to GitHub and PyPI
- [ ] Add background music (optional, low volume)
- [ ] Export as MP4 (H.264, 1080p)
- [ ] Upload to YouTube (unlisted or public)
- [ ] Update README with video embed (optional)

## Quality Checks

- [ ] Terminal text is readable
- [ ] Commands are visible and correct
- [ ] Output is visible and correct
- [ ] No sensitive information exposed
- [ ] Audio is clear (if narrating)
- [ ] Transitions are smooth
- [ ] Total duration is under 3 minutes

## Distribution

- [ ] Embed in README.md (optional)
- [ ] Add to GitHub Release assets
- [ ] Share on social media (Twitter, LinkedIn, Reddit)
- [ ] Add to dev.to / Hashnode post
