## Key Features

1. **Executive Summary** — Clear scan status with PASS/MISSING/LIMITED indicators and reasons for failures
2. **Health Score** — Deterministic weighted scoring (Website Reachability 15%, SEO 20%, Metadata 15%, Technology 20%, Content 20%, Social 10%)
3. **Business-Friendly Language** — No `technology_items`, `metadata_items`, etc. Uses "Technology Detected", "Metadata Found", etc.
4. **Missing Data Explanations** — Every missing section explains WHY data is missing
5. **Diagnostics Moved to Bottom** — Technical details are still available but not prominent
6. **Professional Footer** — Version, GitHub URL, PyPI URL
7. **Tables** — Technology and Social sections use clean Markdown tables
8. **Content Hierarchy** — Headings show proper Markdown hierarchy (# ## ###)
