# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| 0.x     | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in AIFME Scout OSS, please report it responsibly.

**Do not** open a public issue for security vulnerabilities.

Instead, please email [security@aifme.com](mailto:security@aifme.com) with:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment:** Within 5 business days
- **Initial assessment:** Within 10 business days
- **Fix coordination:** As agreed with the reporter

## Disclosure Policy

- We follow coordinated disclosure. Please do not publicly disclose the vulnerability until we have published a fix.
- We will credit reporters in the security advisory unless they prefer to remain anonymous.
- We will work with you to determine the appropriate disclosure timeline.

## Security Best Practices for Users

- Keep Scout OSS updated to the latest version
- Do not run Scout OSS with elevated privileges
- Be cautious when scanning untrusted URLs
- Review generated reports before acting on their contents
- Use virtual environments for isolation
