# Roadmap

AIFME Scout OSS is in **maintenance mode** as of v1.0.0. The roadmap reflects the maintenance policy: only P0/P1 bug fixes, security updates, and AIFME-required changes are accepted.

## AIFME Platform

The commercial AIFME Platform adds capabilities beyond the open-source Scout OSS:

- **Remember** — Persistent memory and scan history
- **Reason** — LLM-backed analysis and recommendation generation
- **Decide** — Automated decision-making based on collected intelligence
- **Execute** — Action execution on behalf of the user
- **Measure** — Outcome tracking and ROI measurement

Learn more at [aifme.com](https://aifme.com).
