# LinkedIn Announcement

I'm excited to share that **AIFME Scout OSS v1.0.0** is now generally available.

After months of engineering work, we've released a free, open-source toolkit that scans any public URL and produces a structured, evidence-linked snapshot of what a business is, how its site is built, and how it compares to named competitors.

**What it does:**
- Scans websites safely (SSRF protection, robots.txt awareness)
- Extracts technology stack, SEO signals, content, metadata, social profiles
- Produces schema-validated JSON and executive Markdown reports
- Exposes both CLI and REST API interfaces

**The numbers:**
- 520 tests, all passing
- 9/10 real-world sites scanned successfully in validation
- 0 crashes, deterministic output verified
- 11 business classifications with confidence scores

Built for competitive intelligence teams, SEO auditors, and developers who need structured website data without the overhead of commercial tools.

**Apache 2.0 licensed. pip install aifme-scout.**
